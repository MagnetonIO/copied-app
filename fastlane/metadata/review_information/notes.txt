Version 1.3.4 (19) is a bug-fix update to the approved Mac App Store version 1.3.3 (17).

Changes:
- Fixed concurrent access to iCloud sync metadata that caused a segmentation fault during sync.
- Improved Up/Down keyboard scrolling past the visible clipping-list boundary while preserving native selection and mouse scrolling.

Validation: sync-state regression tests passed with Thread Sanitizer; the final targeted Mac run passed keyboard navigation across 200 mixed-height clippings, copy commands, global shortcut, and persistence checks. No data reset is required.

Copied App is a menu bar clipboard manager. After install, its icon appears in the system menu bar — click it or press ⌃⇧C from any app to open the popover and view clipboard history. No Copied account or sign-in is required. An iCloud account is needed to exercise cross-device sync.

In-App Purchase:
iCloud Sync is an already-approved $4.99 non-consumable in-app purchase (product ID: com.magneton.copied.icloud_sync; IAP Apple ID: 6764169200). The existing product is unchanged. Without it, clipboard history is stored locally only. To test the purchase flow:

1. Open Settings (⌘,) → Sync tab
2. Click "Unlock iCloud Sync"
3. Complete the purchase via a sandbox tester account
4. The app will prompt to quit and relaunch
5. On relaunch, iCloud Sync becomes active — confirmed by "Sync is active" indicator

"Restore Purchases" is available in the same Sync tab.

Permissions:
The Mac App Store build does not request or use macOS Accessibility access. The global shortcut (⌃⇧C) uses Carbon RegisterEventHotKey, without a keyboard event tap. Selecting a clipping copies it to the clipboard; the user pastes with ⌘V in the destination app. No synthetic keyboard events are sent.
